WR-Games gives you three purpose-built event types so every gathering — whether it's a focused two-player duel, a casual bring-your-own-games night, or something entirely unique — has the right structure behind it. Choosing the correct type up front means less setup work for you and a clearer experience for your attendees.

## Game Session

A Game Session is the simplest event type on WR-Games. You pick one title from the game catalog — or add a custom entry if the game isn't listed yet — and build the event around it. Everything on the event page signals to attendees exactly what they're signing up to play: the game's name, cover art, player count, and any notes you add about the edition or house rules you'll use.

Game Sessions are ideal when you want to finally get a specific game to the table. Because the focus is narrow, it's easy for potential attendees to decide quickly whether they want to join.

**Key details:**

- Tied to a single game from the catalog (or a custom title you add)
- Set a capacity to match the game's player count
- Invite specific people or leave it open to your group
- **Always free to host** — no event credit required, regardless of whether you host inside a group or from your personal hub

## Open Game Night

An Open Game Night is a multi-game meetup. No single title is required — instead, attendees use **On the Table** to share which games they plan to bring, and can form tables around a specific game. This creates a live, crowd-sourced library for the evening so everyone can see what will be played before they arrive.

Open Game Nights work especially well for game stores, clubs, and community spaces that want to run recurring casual nights. New players appreciate the low-pressure format: they don't need to know any specific game in advance, and they can browse On the Table to see something that interests them.

**Key details:**

- Supports multiple games in a single session
- Attendees add games to **On the Table**, and tables form around specific games
- Great for casual meetups, new-player nights, and large group gatherings
- Requires an **event credit** when hosted outside a group (see note below)

## Custom Event

A Custom Event gives you complete control over the format. You write the title, craft the description using the rich text editor, and structure the event however makes sense for your occasion — tournament, teach night, campaign session, game swap, or anything else. None of the fields are pre-shaped around a specific game or format.

Use a Custom Event when Game Session and Open Game Night don't fit your needs. Because the format is open-ended, the description field does a lot of the work — take the time to explain what attendees should expect.

**Key details:**

- Fully freeform title, description, and structure
- Supports any format or occasion
- Includes **On the Table**, plus a pinned game if the occasion calls for one
- Requires an **event credit** when hosted outside a group (see note below)

## Location options

All three event types support the same set of location choices:

- **In-person — physical address:** Enter a street address directly. A weather forecast will appear on the event detail page for in-person events.
- **In-person — saved venue:** Choose from saved venues in your area such as game stores, cafés, or community spaces.
- **Online:** Select a platform such as Board Game Arena, Tabletop Simulator, or another virtual table.

<Note>
  Game Sessions are always free to host. Open Game Nights and Custom Events hosted outside of a group each require a **\$2 event credit** at the time of publishing.
</Note>

## Changing an event's type

Set an event up as one type and then find it doesn't fit? A group host can change the type after publishing without starting over. The common case: you created a Game Session for one game, more people signed up than one copy seats, and now you need tables. Game Session doesn't do tables. Open Game Night and Custom Event do.

The event keeps its link, its RSVPs, and its attendees. What it may not keep is the pinned game and everything on **On the Table**, and that depends on which type you switch to.

<Note>
  Only group-hosted events can change type. An event you host from your personal hub stays the type you created it as. Because of that, changing type never costs an [event credit](/billing/event-credits) — credits only apply to events hosted outside a group.
</Note>

### What each type gives you

| Event type | Pinned game | On the Table |
| :-- | :-- | :-- |
| Game Session | Yes | No |
| Open Game Night | No | Yes |
| Custom Event | Optional | Yes |

### How to change it

<Steps>
  <Step title="Open Manage in the event wizard">
    Open the event, then choose **Change event type** from the **Manage** menu in the wizard header.
  </Step>
  <Step title="Pick the new type">
    You'll see the two types your event isn't. Select one and the dialog spells out what changes, including a count of anything that gets removed and how many people will be notified.
  </Step>
  <Step title="Confirm, then set up the new type">
    Select **Change type**. You'll land on **What kind of event?** to adjust the new type's settings, then save the way you normally would.
  </Step>
</Steps>

### What gets removed

| Change to | What's removed |
| :-- | :-- |
| Game Session | All tables, and all games On the Table |
| Open Game Night | The pinned game |
| Custom Event | Nothing |

When tables go, anyone holding a spot at one is notified right away. You don't have to chase them yourself.

<Warning>
  Removals happen the moment you confirm, and the dialog says so plainly: **This cannot be undone.** You can change the type back afterwards, but the tables and games that came off don't come back with it.
</Warning>

### If the event repeats

For an event in a recurring series, you also pick how far the change reaches: **This event only**, **This and all following**, or **All upcoming events in the series**. Past events in the series can't be changed. They stay as they were.

Either of the wider options overwrites changes you made to individual occurrences, so if you've set one night up differently on purpose, change that one on its own.
