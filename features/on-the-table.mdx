On the Table is where everyone puts down what they're bringing, what they want to play, and who's sitting at which game. Instead of showing up and asking "so what are we playing," you already know.

You'll find it as a tab on the event page. Open Game Nights always have it, and hosts can switch it on for other events too.

## Which Version You're Looking At

Hosts choose how much of On the Table to turn on, so it doesn't look the same at every event. There are three setups, and each one builds on the last.

<Tabs>
  <Tab title="Just Tables">
    You see a **Games** tab and a **Tables** tab. People add the games they're bringing, anyone can open a table for a game, and you grab a seat first come, first served.
  </Tab>
  <Tab title="Voting">
    Same as above, plus an **Up for vote** tab. You can now request a game nobody's bringing yet, and back any game with a vote so the room can see what people actually want to play. Seats are still first come.
  </Tab>
  <Tab title="Ranked">
    The vote tab becomes **Rankings**. Instead of one flat vote, you put the games you'd play in order, and WR-Games seats you automatically based on that order. See [Ranked Seating](/features/ranked-seating) for how that works.
  </Tab>
</Tabs>

<Note>
  You need to be RSVP'd as **Going** to add a game, vote, or take a seat. Anyone can look. At some events the host keeps the list to themselves, in which case you'll see the games but no **Add a Game** button.
</Note>

## Adding a Game You're Bringing

<Steps>
  <Step title="Open the On the Table tab">
    Go to the event page and select **On the Table**. The Games tab shows everything already added.
  </Step>
  <Step title="Press Add a Game">
    You can pick from your own collection, your group's collection, or the full games directory. If it isn't in the catalog yet, search BoardGameGeek and it'll get pulled in.
  </Step>
  <Step title="Select as many as you want">
    It's multi-select, so if you're hauling a bag of five games you add them in one go.
  </Step>
  <Step title="Open a table, or don't">
    Adding a game just says you're bringing it. If you also want to run it, open a table and set how many seats there are.
  </Step>
</Steps>

If two people bring the same game, it doesn't clutter the list. Everything groups into one card per game with a count of how many copies are coming.

## Requesting a Game

When voting is on, the Add a Game dialog has a **Bringing / Requesting** switch at the bottom.

**Bringing** means the game is coming because you're putting it in your bag. **Requesting** means "I'd love to play this, someone bring it or teach it." There's no copy behind a request. It's a wish, not a promise.

The switch picks a sensible default based on where you're browsing. Games from your collection default to Bringing. Games from the directory default to Requesting. Flip it before you commit if the default guessed wrong.

A request shows up as its own card marked **Request · nobody's bringing it yet**, with an **I'll bring it** button. Requests don't carry anyone's name, deliberately. It's the room asking, not one person.

<Info>
  If you own the game and tap **I'll bring it**, the request becomes your bringing entry and every vote it collected comes with it. Nobody has to re-vote.
</Info>

<Warning>
  You can't open a table for a game that's only been requested. Somebody has to actually be bringing a copy first.
</Warning>

## Voting

Voting is the room saying what it wants to play. Tap the **▲** pill on any game card to back it, tap again to take it back. Vote for as many games as you like.

- Vote counts are public, and so are the faces. You'll see an avatar cluster of who backed each game.
- Sort the list by **Most votes** or **Newest** using the control next to Add a Game.
- Once a game has a table running, it drops off the vote list. It's happening, so there's nothing left to vote on. If every table for it gets cancelled, it comes back with its votes intact.

<Warning>
  Your votes are tied to you being there. If you change your RSVP away from Going, your votes are removed for good. Coming back to Going doesn't restore them, you'd vote again. And if a request loses its last vote, the request disappears, because nobody's asking for it anymore.
</Warning>

## Taking a Seat at a Table

A table is a specific game at a specific time with a set number of seats.

1. On the **Tables** tab, find the game you want.
2. Open it to see who's leading it, who's already sitting there, and how many seats are left.
3. Press **Join** to take a seat.

Tables are either a fixed size, usually somewhere between 2 and 20 seats, or **drop-in** with no limit. Seats go first come, first served, so if a table you want is full, keep an eye on it. There's no waiting list and nothing will notify you if a seat frees up, so check back closer to the event.

You can sit at more than one table across a night. An evening usually has room for a couple of games.

<Note>
  Whoever creates a table is its **lead**. If the lead stops going, the table is cancelled and everyone sitting at it gets notified. If you're leading a table and can't make it, hand the lead to someone else before you change your RSVP so the game still happens.
</Note>

## After the Event

On the Table stays put once the night is over. It becomes the record of what was actually played, and it feeds the game stats your organizer sees.

Hosts get a **7-day window** after an event ends to tidy things up: add a game that got played on a whim, fix who brought what, or remove something that never showed. After that, the list locks as part of the event's history.
