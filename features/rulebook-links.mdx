Every game page on WR-Games has a **Rules** card. When we have a rulebook for the game, the card links straight to it, so you can check a rule before game night or settle one at the table.

## Where to Find It

Open any game's page and scroll to **Learn & Resources**. The **Rules** card is the first card there.

## What the Rules Card Shows

| What You See | What It Means |
| :-- | :-- |
| A card with one rulebook | Select the card to open the rulebook in a new tab |
| A **+N** button on the card | There's more than one copy. Select **+N** to see them all |
| "Rules are coming soon." | We don't have a working link for this game yet |

Beside the word **Rules**, a label tells you where the copy comes from:

| Label | Where the Copy Comes From |
| :-- | :-- |
| **Official** | The publisher's own copy. The card shows the publisher's name |
| **Trusted** | A well-known board game site. The card shows "From" and the site's name |
| **Third party** | Another site. The card shows "From" and the site's name |

### Seeing Every Copy

Select **+N** to open **Rulebook Sources**. On a computer it opens beside the card, and on a phone it slides up from the bottom of the screen. Each copy has **Open**, which opens it in a new tab, and a flag for reporting it.

## Report a Link

We check these links on a schedule. If you find one that's broken, points to the wrong game, or shouldn't be there, report it. You don't need to be signed in.

<Steps>
  <Step title="Select the Flag">
    On the card, the flag sits in the corner. In **Rulebook Sources**, every copy has its own. Both open **Report This Link**.
  </Step>
  <Step title="Tell Us What's Wrong">
    Under **What's Wrong?**, choose **This link doesn't work**, **Wrong game or edition**, or **Remove this link (I own the rights)**.
  </Step>
  <Step title="Add Your Email If You'd Like a Reply">
    **Email (Optional)** is only for a reply. Leave it blank if you don't need one.
  </Step>
  <Step title="Send the Report">
    You may see a quick security check first. Then select **Send Report**.
  </Step>
</Steps>

<Check>
  **Report Sent.** A person reviews every report, and someone on our team will look at the link.
</Check>

If you hold the rights to a rulebook and want its link taken down, choose **Remove this link (I own the rights)** and add your email so we can get back to you.

<Note>
  **The security check won't load?** Try another browser, or email [support@wr-games.com](mailto:support@wr-games.com).
</Note>
