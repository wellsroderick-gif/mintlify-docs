title: "Why Can't I Remove a Game from My Group?"
description: "If WR-Games blocked a game removal from your group library, here's why, and what to do instead."
sidebarTitle: "Can't Remove a Game?"
---

Seeing **This game is shared automatically** when you try to remove a game from your group's collection? The game is in one of your collection folders that syncs to this group, so WR-Games would just add it back.

The game isn't stuck. You just need to go one level up.

## Why This Happens

Each folder you sync to a group shares its games there for you:

- **Owned Games** shares the games you own.
- Any other folder shares every game in it, owned or not.

While a game is in a folder that syncs to this group, removing it from the group on its own would be undone straight away, so WR-Games stops you and points you to the controls that fix it.

## What to Do Instead

<Tabs>
  <Tab title="Stop Syncing the Folder">
    <Steps>
      <Step title="Open the Auto Sync Tab">
        Select **Turn off auto-sync for this group**, or open the group's **Collection** tab, select **Contribute to This Group** and choose **Auto Sync My Collection**.
      </Step>
      <Step title="Switch the Folder Off">
        Turn off the folder the game is in. Choose **Remove synced games** to take everything that folder shared out of the group, or **Keep games, stop sync** to leave them. Kept games can then be removed one at a time.
      </Step>
    </Steps>
  </Tab>
  <Tab title="Take the Game Out of the Folder">
    Select **Manage my collection** and remove the game from the folder. It leaves the group too, unless another folder you sync to this group still has it.
  </Tab>
</Tabs>

<Tip>
  If you no longer own the game on BGG, re-syncing your collection takes it out of **Owned Games**, so Owned Games stops sharing it.
</Tip>

<Note>
  Switching a folder off never touches games you added to the group by hand. Only games the folder shared can be removed.
</Note>
