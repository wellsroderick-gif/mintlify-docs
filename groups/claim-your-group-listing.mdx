WR-Games holds directory listings for board game groups we found on Meetup. A listing is a live page with its own web address. It shows the group's upcoming Meetup events, and people can find it in search. What it doesn't have yet is an organizer.

If you organize that group, you can claim its listing and run it on WR-Games.

## How to Spot an Unclaimed Listing

An unclaimed listing carries an **Unclaimed** badge in the metadata row on the group page, alongside location, source, and visibility.

<Note>
  Nobody can join a listing while it's unclaimed. Membership opens once the group has an organizer, so claiming is also what lets people start joining.
</Note>

## Claiming Your Listing

You claim a listing from the same place you'd import a Meetup group. There's no separate claim button to hunt for.

<Steps>
  <Step title="Start a Meetup Import">
    Open the import wizard and paste your Meetup group URL, exactly as you would to [import a group](/groups/import-from-meetup) for the first time.
  </Step>
  <Step title="Let the Wizard Recognize Your Group">
    Rather than building a new group, the wizard tells you **We already have a page for this group** and shows you what it found: cover image, name, city, and how many upcoming events are already on the page.
  </Step>
  <Step title="Review the Details and Pick Your RSVP Mode">
    Same choices as a normal import. [Meetup Integration](/groups/meetup-integration) covers the difference between link-out and side-by-side.
  </Step>
  <Step title="Confirm You're Authorized">
    Tick **I confirm I'm authorized to run this group**, then claim it. The page is yours from that moment.
  </Step>
</Steps>

## Nothing Resets When You Claim

Claiming takes over the page you're looking at. It doesn't build a second one.

| What people already have | What claiming does to it |
| :-- | :-- |
| The link they've been sharing | Keeps working |
| Events already on the page | Stay exactly where they are |
| Upcoming events on Meetup | Keep syncing across |
| Search results pointing at the page | Keep pointing at it |

You also get everything a brand-new group gets: settings, the forum, member tools, and the RSVP mode you picked in the wizard.

<Tip>
  You can change your group's web address later if you want a different one. Claiming doesn't lock you in, and it doesn't break the link people already have.
</Tip>

## What You Get on WR-Games

- **Roll Call** for tracking who's actually coming
- **Search by game**, so players find your events through the games on the table
- **Event tools built for board games**

## Claiming Is First Come, First Served

WR-Games doesn't verify that you run a group before letting you claim its listing, the same way Meetup import has always worked. The attestation checkbox is the check.

Because of that, the claim screen makes a commitment:

> **Please note:** if another organizer proves they run this group, WR-Games will transfer it to them.

## If Someone Else Claimed Your Group

You can still get it back. Get in touch and tell us which group it is and that you run it, and we'll take it from there.

The page transfers across intact. It isn't rebuilt from scratch, so the link, the events already on it, and the settings all come with it.

[Contact us](/help/contact) to start that conversation.
