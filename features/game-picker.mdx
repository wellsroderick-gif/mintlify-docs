Whenever WR-Games asks you to choose a game, you get the same picker: game covers, tabs across the top, and a search box. It looks and behaves the same whether you're adding a game to On the Table, setting up an event, or adding to a group's collection. What changes from screen to screen is what happens after you pick.

## Where You'll See It

| Where You Open It | What Picking Does |
| --- | --- |
| **Add a Game** on On the Table | Tick as many covers as you like, then settle who's bringing each one. See [On the Table](/features/on-the-table). |
| **Start a Table** | Pick one game from a compact list, then choose whose copy it's on. |
| **Pick a Game** and **Pick Cover Art** in the event wizard | Tap a cover and it's picked. The picker closes. See [Creating Events](/features/creating-events). |
| Logging a play, and the game choice on Insights | Tap a cover and it's picked. See [Play Logging](/features/play-logging). |
| Adding games to a group's collection, **Assign Games**, and **Add Games** in My Collection | Tick covers, then confirm. See [Your Game Collection](/features/game-collection). |

## The Three Tabs

| Tab | What's in It |
| --- | --- |
| **My Collection** | The games in your own collection. |
| **Group Collection** | Games the group's members have added. Covers show who owns each one, and you can filter by owner. This tab only appears when the picker is working for a group that has its collection switched on. |
| **Games Directory** | Every game in the WR-Games catalog. It lists games before you type anything. |

Each picker opens on the tab you used last time you were in it. If you haven't used it before, or that tab has no games, it opens on Group Collection if the group has games, then My Collection if you own games, then Games Directory. The event wizard has no Group Collection tab.

## Searching

Type in the search box. On My Collection and Group Collection, search narrows the games already listed. On Games Directory, it searches the whole catalog.

If a search turns up only a few games in WR-Games, the first batch of BoardGameGeek results appears on its own, under its own label. Select **Show More** to load the next batch. You can also switch on **Search BoardGameGeek** to search there from the start. It's off each time you open the picker.

<Note>
  Start a Table doesn't search BoardGameGeek.
</Note>

## What the Labels on a Game Card Mean

Cards tell you where a game already stands, so you don't add it twice.

**On the Table**

| Label | What It Means |
| --- | --- |
| **You're Bringing** | You already bring this game. It can't be ticked again. |
| **Sarah's Bringing** (or whoever's name it shows) | Someone else is bringing it. You can still tick it, and then you bring another copy. |
| **Already Requested** | Someone has asked for this game. Pick it as a request and your vote is added to theirs. Pick it to bring and the request becomes your copy, with its votes kept. |
| **You Voted** | You've already voted for this request. Ticking it changes nothing. |

**Adding to a Group's Collection**

| Label | What It Means |
| --- | --- |
| **Added** | One of your own copies is already in the group. It can't be picked again. |
| **In group** | Another member has already added this game to the group. You can still pick it. |

<Info>
  In **Add Games** on My Collection, **Added** is only a label. You can still pick the game.
</Info>
