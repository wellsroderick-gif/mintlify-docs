WR-Games event creation uses a guided wizard that walks you through every setting in a logical order, so nothing important gets overlooked before you publish. Whether you're planning a quick game session for the weekend or setting up a recurring club night, the same flow applies.

## Creating an Event

<Steps>
  <Step title="Start From Your Group or Hub">
    Navigate to your group and click **Create Event**, or click **Create Event** from your personal hub if you're hosting independently. If you're creating inside a group, the event is automatically associated with that group.
  </Step>
  <Step title="Choose an Event Type">
    Select one of the three event types: **Game Session**, **Open Game Night**, or **Custom Event**. Each type shapes the fields available in the following steps. Not sure which to pick? See [Event Types](/features/event-types) for a full breakdown.
  </Step>
  <Step title="Set the Date, Time, and Timezone">
    Enter the date and start time, then confirm the timezone. Everyone sees the event's time in the timezone you choose, shown with its abbreviation, like 7pm CDT. It isn't converted to each person's own time.
  </Step>
  <Step title="Add a Location">
    Choose one of three location formats:

    - **Saved venue**: pick a game store, café, or community space from the saved venues list
    - **Physical address**: enter a street address directly; a weather forecast will appear on the event page
    - **Online platform**: select Board Game Arena, Tabletop Simulator, or another virtual table
  </Step>
  <Step title="Set Capacity and RSVP Deadline (Optional)">
    Enter a **maximum attendee count** if you need to limit the guest list. When the event reaches capacity, new RSVPs go to the automatic waitlist. Set an **RSVP deadline** if you need to close RSVPs before the event starts, useful when you need a firm headcount in advance.
  </Step>
  <Step title="Write a Description">
    Use the rich text editor to add everything attendees need to know: what to expect, what to bring, house rules, parking notes, or anything else relevant. Formatting tools let you use headings, bullet lists, bold text, and links.
  </Step>
  <Step title="Choose Visibility">
    Select who can see and RSVP to the event:

    - **Public**: visible to anyone on WR-Games
    - **Unlisted**: only accessible via direct link
    - **Invite-only**: only users you explicitly invite can see and RSVP to the event (available on the **Pro plan** for user-hosted events)
  </Step>
  <Step title="Publish or Save as Draft">
    Click **Publish** to make the event live, or **Save as Draft** to come back and finish it later. Drafts are only visible to you and any Co-Hosts you've added.
  </Step>
</Steps>

## Picking the Game

When you create a Game Session, the wizard asks for the game right after the event type, on a step called **Choose a Game**. Press the game box to open **Pick a Game**. If you're editing an event that's already published, the game sits on the Details step and opens the same picker.

Pick a Game is the [game picker](/features/game-picker) with two tabs. Tap a game and it's picked. The picker closes by itself, so there's no checkbox and nothing to confirm.

| Tab | What's in It |
| --- | --- |
| **My Collection** | The games you own. |
| **Games Directory** | Every game in the WR-Games catalog. |

Each time you open it, the picker starts on the tab you used last.

### Narrowing the List

- **Search** works on both tabs. If a Games Directory search finds only a few games in WR-Games, BoardGameGeek results fill in below. You can also switch on **Search BoardGameGeek** to search there from the start.
- **Folders** show as pills across the top of My Collection once you have more than one. On a computer, **Manage Collection** opens your folders in a new tab, so you don't lose the event you're setting up.
- **Filters** for weight, players and playtime sit under the search box. Games Directory adds a fourth, for rating. My Collection doesn't have one.
- **Show Expansions** is a switch on My Collection. It's off until you turn it on, and WR-Games remembers your choice. When it's on, expansions you own are listed too, each marked with an **Expansion** label.

### When You Pick an Expansion

Picking an expansion brings up **Switch to the Base Game?**

<Info>
  Choose **Continue** and the base game becomes the event's game, with the expansion included as its expansion. The event is linked to both. Choose **Keep My Pick** and the expansion stays as the event's game on its own.
</Info>

If WR-Games doesn't have the base game, you won't be asked. Your pick stands.

## Cover Image

Every event has a cover image. On events with a game attached, a Game Session or a Custom Event with a game pinned, you choose which image that is. You choose it in the event wizard, and it works the same whether you're creating an event or editing one that's already published.

There are three ways to set it:

<Columns cols={3}>
  <Card title="Upload Your Own" icon="upload">
    Any image you like. Works on every event type, with or without a game.
  </Card>

  <Card title="Use Game Art" icon="dices">
    A row of thumbnails: your pinned game first, then each expansion you've selected.
  </Card>

  <Card title="Pick Cover Art" icon="search">
    Choose any game's box art, from your collection or the Games Directory, whether or not it's on your event.
  </Card>
</Columns>

### Picking Cover Art

**Pick Cover Art** is the same picker you used for the game, with the same two tabs. Tap a game and its box art becomes your cover.

- **My Collection** lists your whole collection here, owned or not. A game on your wishlist works as well as one on your shelf.
- **Games Directory** has every game in the catalog.
- There are no folders, filters or **Show Expansions** switch, because you're only looking for art.

You can open it from the cover picker on the Game step or on Details.

### Expansion Art

Select three expansions and you get three thumbnails, in the order you picked them, each labelled with that expansion's name. There's no rule about which expansion "wins" and nothing is chosen for you. They're just more options in the row.

If an expansion has no box art in the catalog, its thumbnail still appears but greyed out. That's deliberate. An expansion vanishing from the row while you can see it selected right above looks like a bug, whereas a greyed tile tells you the truth: there's no art to use.

Game art is shown whole rather than cropped, so a tall box doesn't get its top and bottom sliced off.

### Two Things Worth Knowing

**Once you choose an image, it stays chosen.** If you pick an expansion's art and later deselect that expansion, your cover doesn't revert. The same goes for switching the base game afterwards. WR-Games only fills the cover in automatically when you haven't made a choice, and picking the base game's own art on purpose counts as a choice.

<Note>
  The one exception is clearing the game entirely. Art you picked depicts the game you just removed, so it goes with it and you'll be back to no cover. An image you uploaded yourself never depicted the game, so it stays put.
</Note>

## Editing an Event

You can edit most fields on an upcoming event at any time before it starts. Navigate to the event page, click **Edit Event**, make your changes, and save.

Most edits are quiet: changing the description, swapping a game, or fixing a typo won't ping anyone. **Moving the date or time is different.** How far you move it determines what WR-Games sends on your behalf:

| How Far You Move It | What Happens |
| --- | --- |
| **Less than 24 hours** | Nothing re-sends. A small nudge stays quiet. |
| **24 hours or more** | [Roll Call](/features/roll-call) re-opens and every previous confirmation is cleared. Attendees are asked to confirm again for the new date. |
| **72 hours or more** | Roll Call re-opens _and_ the 24-hour reminder emails re-send closer to the new date. |

<Tip>
  Other changes (venue, description, capacity) don't notify anyone on their own. If you make a significant non-schedule change, post in the event's discussion thread to give attendees a heads-up.
</Tip>

## Adding Co-Hosts

Co-Hosts share hosting with you. They can edit event details, manage RSVPs, and perform check-ins. There are two ways to add one:

<Columns cols={2}>
  <Card title="In the Event Wizard" icon="wand-sparkles">
    Add them in the **Co-Hosts** field while you create or edit the event.
  </Card>

  <Card title="From the Attendees Tab" icon="users">
    Open the menu on someone's row and choose **Add as Co-Host**. On your own row it reads **Make Me a Co-Host**.
  </Card>
</Columns>

<Note>
  Every host on an event has the same standing. There's no lead host to promote or step down from, and anyone you add is told they're now hosting.
</Note>

Co-Hosts must have a WR-Games account.

## Inviting People to an Invite-Only Event

An invite-only event is visible only to the people you invite. You can invite friends, members, or anyone by email address, while you create the event or any time after.

On a published invite-only event, open the **Invitations** tab. Under **Add More Invitees**, pick people or enter email addresses, then select **Invite**. Invitations go out right away.

Each person on the tab shows where they stand:

| Status | What It Means |
| --- | --- |
| **Invited** | Sent, with no answer yet. You can **Revoke** it, and invite them again later if you change your mind. |
| **Accepted** | They RSVP'd Going. |
| **Waitlisted** | They said yes, but the event was full. |
| **Declined** | They RSVP'd Not Going. |
| **Claimed** | An invitation sent by email has been picked up by a WR-Games account. |

<Tip>
  You get a notification when someone accepts, so you don't have to keep checking the tab.
</Tip>

There's a limit on how many invitations one account can send in a day. If you reach it, the tab tells you.

## Duplicating an Event

Duplicating copies all settings from an existing event (type, description, location, capacity, and visibility) into a new draft with a blank date and time. It's useful for one-off repeats or when you want to reuse a template without rebuilding from scratch each time.

To duplicate, open the event page, click the **⋯** menu, and select **Duplicate Event**. The duplicate opens as a draft; update the date and any other details, then publish.

<Tip>
  If you run the same event regularly, use a **recurring series** instead of duplicating manually. Recurring series keep all sessions linked, making it easy to manage attendance patterns and series-level details. Recurring series are available on **Standard and higher plans**.
</Tip>

## Canceling an Event

Cancelling an event notifies all current attendees immediately. The event stays visible on WR-Games with a **Cancelled** label so attendees who check back can see what happened. You can add a cancellation message to explain the reason.

To cancel, open the event management panel and select **Cancel Event**. This action cannot be undone: if your plans change again, you'll need to create a new event.

## Deleting an Event

Deleting an event removes it permanently. Anyone who visits the old event URL is redirected to the main `/events` page or the group's event list. Unlike cancellation, deletion sends no attendee notification, so cancel first if attendees need to know.

<Warning>
  Deleting an event is permanent and cannot be reversed. If attendees are already signed up, cancel the event instead so they receive a notification.
</Warning>
