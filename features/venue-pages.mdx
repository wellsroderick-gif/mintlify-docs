Every game store, café, library and community space in the venue directory has its own page. It's where you check whether a place is open, see what's being played there, and find your way in the door.

## The Top of the Page

Next to the venue's name is a badge that tells you how far it's been checked.

| Badge | What It Means |
| :-- | :-- |
| **Official** | The venue's owner runs this page on WR-Games. |
| **Community Verified** | Members added it and it's been checked, but nobody from the venue runs the page yet. |
| **Pending Verification** | Recently added and still being checked. |

Below the name you'll see whether the venue is **Open Now** (with when it closes) or **Closed**, its address and type, how many upcoming events it has, and its website.

<Note>
  If a venue has closed for a while or for good, a banner at the top says so. Events there stay listed, so check with the host before you go.
</Note>

## The Tabs

| Tab | What's on It |
| :-- | :-- |
| **About** | The venue at a glance: the next event, its description and amenities, upcoming events, hours and directions |
| **Events** | Every upcoming event at the venue, in date order |
| **Calendar** | A calendar view of what's on, plus a **Subscribe** link for your own calendar app |
| **Reviews** | Not open yet |
| **Games** | Not open yet |

On a phone, the tabs sit in a bar along the bottom of the screen. A tab shows a count when it has something to count.

## The About Tab

### The Main Column

- **The spotlight:** a large card for the venue's next event, marked **Happening Tonight** when it's today or **Next Up** when it isn't. Select **View Event** to open it.
- **About:** the venue's own description, and chips for its amenities, like Wi-Fi, Serves Food or Public Restroom.
- **Community Events Here:** events run by groups and people other than the venue. **View All** opens the Events tab.
- **Upcoming Events:** the next few events of every kind. **Full Calendar** opens the Calendar tab.

### The Side Column

- **Hours:** the regular week, any hours note, and an **Upcoming Changes** box when the venue has special hours in the next 14 days.
- **At a Glance:** quick facts the venue has filled in, like capacity, a menu link or **Public Restroom**, plus how many events it has hosted.
- **Accessibility:** step-free entrance, accessible restroom and the rest, when the venue has filled them in.
- **Map and contact:** the address, any **How to Find Us** note from the venue, **Get Directions**, phone, website and social links.
- **Getting There:** when it's available, the nearest train station and bus stop, how long the walk is, and parking.

### Public Restroom

**Public Restroom: Yes** means anyone can use the venue's restroom, not only paying customers. It's separate from the accessibility details. If the venue hasn't filled it in, it doesn't show.

In the venue directory, the **Public Restroom** filter shows only venues that said **Yes**.

## Event Labels

Every event at a venue carries one of three labels, so you can tell at a glance who's running it.

| Label | Who Runs the Event |
| :-- | :-- |
| **Official** | The venue itself |
| **Partner** | A group or person the venue works with |
| **Community-Led** | Anyone else hosting there |

Labels only mark a card. They never change the order, so every list on a venue page runs by date.

## What You Can Do on a Venue Page

Some actions are buttons at the top of the page. The rest are in the **⋯** menu.

| Action | Where | Who Sees It |
| :-- | :-- | :-- |
| **Share** | Top of the page | Everyone |
| **Create Event** | Top of the page | Signed-in members. It starts a new event with this venue already picked. |
| **Manage Venue** | Top of the page | The venue's owner and team |
| **Claim This Venue** | ⋯ menu | Signed-in members, on a venue with no owner yet |
| **Suggest an Edit** | ⋯ menu | Signed-in members, when the venue offers it |
| **Flag Inaccurate Info** | ⋯ menu | Signed-in members, on a venue that has an owner |
| **Report** | ⋯ menu | Signed-in members |
