## Style preferences

{/* Add any project-specific style rules below */}

- Use active voice and second person ("you")
- Keep sentences concise — one idea per sentence
- Labels take Title Case (AP style); running text takes sentence case. Labels are headings, page titles and sidebar titles, `<Step>`, `<Card>`, `<Tab>` and `<Accordion>` titles, and table column headers. A label is running text, and keeps sentence case, when it ends in `?`, `.` or `!` or is a full clause with its own subject ("I can't sign in"). Lowercase only these words mid-title: a, an, the, and, but, or, nor, for, so, yet, of, to, in, on, at, by, as. Phrasal-verb particles stay capitalized ("Turn Off Transit"). Source: brand brief §6, ruled in WR-8862
- Bold for UI elements: Click **Settings**
- Code formatting for file names, commands, paths, and code references
