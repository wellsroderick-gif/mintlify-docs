On the Table is where everyone puts down what they're bringing, what they want to play, and who's sitting at which game. Instead of showing up and asking "so what are we playing," you already know.

You'll find it as a tab on the event page. Open Game Nights always have it, and hosts can switch it on for other events too.

## Which Version You're Looking At

Hosts choose how much of On the Table to turn on, so it doesn't look the same at every event. There are three setups, and each one builds on the last.

<Tabs>
  <Tab title="Just Tables">
    You see a **Games** tab and a **Tables** tab. People add the games they're bringing, anyone can open a table for a game, and you grab a seat first come, first served.
  </Tab>
  <Tab title="Voting">
    Same as above, plus an **Up for vote** tab. You can now request a game nobody's bringing yet, and back any game with a vote so the room can see what people actually want to play. Seats are still first come.
  </Tab>
  <Tab title="Ranked">
    The vote tab becomes **Rankings**. Instead of one flat vote, you put the games you'd play in order, and WR-Games seats you automatically based on that order. See [Ranked Seating](/features/ranked-seating) for how that works.
  </Tab>
</Tabs>

<Note>
  You need to be RSVP'd as **Going** to add a game, vote, or take a seat. Anyone can look. At some events the host keeps the list to themselves, in which case you'll see the games but no **Add a Game** button.
</Note>

## Adding Games

**Add a Game** opens the [game picker](/features/game-picker). Add as many games as you like, check who's bringing each one, and save them all at once.

<Steps>
  <Step title="Open the On the Table Tab">
    Go to the event page and select **On the Table**. The Games tab shows everything already added.
  </Step>
  <Step title="Press Add a Game">
    Choose **My Collection**, **Group Collection**, or **Games Directory**. If a search finds only a few games in WR-Games, BoardGameGeek results show up too. See [How the Game Picker Works](/features/game-picker) for the tabs and search.
  </Step>
  <Step title="Add the Games You Want">
    Add several in one go. If you're hauling a bag of five games, add all five before you save.
  </Step>
  <Step title="Check Who's Bringing Each One">
    WR-Games makes a first guess for every game. Change it if the guess is wrong. The next section explains the guesses.
  </Step>
  <Step title="Save">
    Press the button at the bottom. It shows your count, like **Add 3 Games**.
  </Step>
</Steps>

<Tabs>
  <Tab title="On a Computer">
    The games you add collect in **Your Table**. Each one shows who's bringing it, with **Change** next to it.
  </Tab>
  <Tab title="On a Phone">
    A bar at the bottom counts the games you've added. Tap **Review** to open **Who's Bringing What**, then tap a game to choose who's bringing it. **Add More** takes you back to the picker.
  </Tab>
</Tabs>

Adding a game just says you're bringing it. If you also want to run it, open a table and set how many seats there are.

If two people bring the same game, it doesn't clutter the list. Everything groups into one card per game with a count of how many copies are coming.

## Who's Bringing It

WR-Games makes a first guess from where you added the game, and you can change it before you save.

| Where You Added It | What You Get |
| --- | --- |
| **My Collection** | You bring it. |
| **Games Directory** | You bring it. |
| **Group Collection**, and you own it | Your copy. |
| **Group Collection**, you don't own it, and an owner is going | A request if voting is on. Otherwise you bring it. |
| **Group Collection**, you don't own it, and no owner is going | You bring your own. |

Each game offers **I'll Bring My Copy** when it's in your collection, **I'll Bring My Own** when it isn't, and **Request It** when voting is on.

If someone else is already bringing a game, you can still add it and bring another copy. A game you already bring can't be added again. The labels on each game's card explain where it stands. See [How the Game Picker Works](/features/game-picker).

## Requesting a Game

When voting is on, **Request It** is one of the choices for each game you add. A request means "I'd love to play this, someone bring it or teach it." There's no copy behind a request. It's a wish, not a promise. **Request It** shows up once you're going to the event.

A request shows up as its own card with a **Request** label, the note "Nobody's bringing it yet," and an **I'll bring it** button. Requests don't carry anyone's name, deliberately. It's the room asking, not one person.

Each game gets one request. If a game is already requested and you request it too, your vote is added to that request and nothing else changes. If you've already voted for it, adding it again changes nothing.

<Info>
  If you own the game and tap **I'll bring it**, the request becomes your bringing entry and every vote it collected comes with it. Nobody has to re-vote. Adding the game as one you're bringing does the same thing.
</Info>

<Note>
  You can't open a table for a game that's only been requested. Somebody has to actually be bringing a copy first.
</Note>

## Adding Games as a Host

Hosts get a few more choices when they add a game.

- **From the Group Collection:** the game goes under its owner's copy. If one going member owns it, that's set for you. If several do, you choose. If none is going, it goes under you.
- **From the Games Directory:** you can put the game under any member who's going. A box lets you also add it to the Group Collection as that member's copy. It starts off, and WR-Games remembers your choice for each person.
- **Telling the member:** adding someone's copy sends them a notification that names the game. They can remove the game, or cancel a table that was set up in their name.
- **Hosts-only lists:** if the list is limited to hosts and you aren't going, you can add games but you can't request them.

## The Two Checkboxes

Two checkboxes can show up under your games before you save.

**Add the game to My Collection.** This shows when you're bringing a game that isn't in your collection yet, and lets you pick the folder it goes in. It starts off. Once you turn it on, WR-Games remembers your choice.

**Let others run tables on my games.** This shows when at least one game you're adding is your own copy. It covers everything you add in that go, and WR-Games remembers your choice for each game. To set it differently for different games, add them separately.

## If a Game Doesn't Save

Each game saves on its own, so one problem doesn't hold up the rest. If a game doesn't go through, the message names it and it stays in Your Table so you can try again. The games that did save are on the list, and a message counts how many were added.

## Voting

Voting is the room saying what it wants to play. Tap the **▲** pill on any game card to back it, tap again to take it back. Vote for as many games as you like.

- Vote counts are public, and so are the faces. You'll see an avatar cluster of who backed each game.
- Sort the list by **Most votes** or **Newest** using the control next to Add a Game.
- Once a game has a table running, it drops off the vote list. It's happening, so there's nothing left to vote on. If every table for it gets cancelled, it comes back with its votes intact.

<Warning>
  Your votes are tied to you being there. If you change your RSVP away from Going, your votes are removed, and coming back to Going doesn't restore them, so you'd vote again. And if a request loses its last vote, the request disappears, because nobody's asking for it anymore.
</Warning>

## Taking a Seat at a Table

A table is a specific game at a specific time with a set number of seats.

1. On the **Tables** tab, find the game you want.
2. Open it to see who's leading it, who's already sitting there, and how many seats are left.
3. Press **Join** to take a seat.

Tables are either a fixed size, usually somewhere between 2 and 20 seats, or **drop-in** with no limit. Seats go first come, first served, so if a table you want is full, keep an eye on it. There's no waiting list and nothing will notify you if a seat frees up, so check back closer to the event.

You can sit at more than one table across a night. An evening usually has room for a couple of games.

<Note>
  Whoever creates a table is its **lead**. If the lead stops going, the table is cancelled and everyone sitting at it gets notified. If you're leading a table and can't make it, hand the lead to someone else before you change your RSVP so the game still happens.
</Note>

## After the Event

On the Table stays put once the night is over. It becomes the record of what was actually played, and it feeds the game stats your organizer sees.

Hosts get a **7-day window** after an event ends to tidy things up: add a game that got played on a whim, fix who brought what, or remove something that never showed. After that, the list locks as part of the event's history.
